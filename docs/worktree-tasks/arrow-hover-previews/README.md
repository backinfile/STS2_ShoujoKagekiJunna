- `src/Combat/ArrowCardPresentation.cs`：已部署牌的回合牌匾读取实时剩余回合；未部署牌继续显示印刷值与升级预览。原生矩形卡图孔与箭矢轮廓之间的透明缺口使用原生牌面纹理和材质补齐，保留银色贴图、卡图与文字布局。
- 新脚本附带 Godot UID。未生成或改写图片素材。
- `src/Combat/ArrowHud.Feedback.cs`：复用原生 Power 的 `PowerFlash` 粒子、闪白材质、缩放曲线及渐隐，替换为当前箭矢轮廓。计数改变时闪光并让数字短暂放大后复位，连续修改会重新开始动画；悬停牌面数字同步轻跳。
- `src/Combat/ArrowCombat.cs`：在剩余回合实际改变时通知 HUD；归零时先亮出 0，短暂停留 0.14 秒，再用 0.3 秒射向目标，目标处出现星形闪光与扩散环。群体箭覆盖每个存活敌人，自身箭飞回角色。使用原生 `Cmd.Wait` 衔接发射与牌效结算，遵循游戏的瞬时模式和战斗结束规则。
- 发射画面独立保留至 0.7 秒结束，避免牌效立即结算后箭矢直接消失；已发射节点停止参与悬停和目标引导，随后自动清理。
- 闪光粒子改为局部坐标，轮廓与旋转中的箭身使用同一变换，修正原来闪光竖直、箭身倾斜的问题。
- `ArrowDeployment` 统一枚举单体与群体目标，展示顺序为玩家全体、单个玩家、敌人全体、单个敌人；单体目标按横向位置分组，同一目标按原始部署序号排序。换目标保留计数、打出顺序与原 `CardPlay` 的资源和重放信息。
- `src/Combat/ArrowLayout.cs` 与 `ArrowHud.Layout.cs`：在固定间距候选槽位上用动态规划分配有序位置，依次最小化已有箭矢的移动数量、总位移，再安排新箭矢的分布。优先插空，必要时扩展行数；移除箭矢时保留其余位置，实际移动采用平滑过渡。时间与回溯空间均为 `O(箭矢数 × 槽位数)`。
- `src/Combat/ArrowCombat.Targeting.cs`：死亡前记录敌人实际横向位置，确认真正死亡后先选右侧最近的可保留目标，再向左回退。没有目标时移入弃牌堆，敌人全体箭也在敌方完全消失时弃置。原生死亡预防、复活保留与不可命中状态会保留原目标；倒计时到 0 也保持等待，恢复可命中后的正常推进继续结算。悬停预览同步新的目标上下文。
- `src/Combat/ArrowPileExit.cs`：原生隐藏牌堆的牌背飞行动画查询起点时没有传入具体卡牌，BaseLib 因此返回画布原点。现在为单张箭矢的牌堆迁移提供实际起点：归零发射使用保留的落点；失去目标而弃置使用当时的悬浮位置。位置通过限定作用域的异步上下文传递，继续使用原生弃牌、回手及消耗流程。
