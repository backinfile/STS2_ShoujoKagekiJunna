# 卡牌原生实现复核

## 依据与修正

本轮读取安装游戏 Beta API 的原生类型，并核对基础版、升级版和本次实际卡池。

| 对象 | 本体参考 | 复核结果 |
| --- | --- | --- |
| 牢笼 | `Colossus.OnPlay`、`ColossusPower.ModifyDamageMultiplicative`、`AfterSideTurnEnd` | 初版在出牌时给已有目标挂减伤，无法跟随本回合新增或改换目标的箭矢。按用户确认改为玩家侧回合能力，结算攻击伤害时查询当前己方箭矢目标；新增、改目标、完成与离场立即反映。沿用巨像对能力持有者所受攻击的判断和敌方回合结束移除的时点，按“不重复”配置单份能力。 |
| 追逐着你而去 | `HowlFromBeyond.AfterAutoPostPlayPhaseEntered`、`HellraiserPower.AfterCardDrawnEarly`、`CardCmd.AutoPlay` | 保留跨牌区实际牌、触发目标和防递归；改用原生 AutoPlay。没有有效继承目标时传入空目标，由战斗同步随机数选敌；受阻时沿原生去向处理。 |
| 齐射、撕裂黑暗、追逐着你而去的内部类型 | `DaggerSpray` 的攻击类型与原生攻击命令；项目箭矢内部类型约定 | 工作台三项内部类型误为技能。通过 MCP 修正为攻击并重新生成，验证实际 `ArrowConversion.Convert` 后为攻击。 |
| 齐射与檄文的多段伤害 | `DaggerSpray.OnPlay` 的 `DamageCmd.Attack`、`WithHitCount`、`TargetingAllOpponents` | 继续沿原生攻击命令结算，核对多段群伤、伤害加成、额外次数和檄文基础／升级伤害。 |
| 专项加练 | `Armaments.OnPlay` 升级版的整堆遍历及资格筛选 | 遍历当前抽牌堆中的实际牌，按项目伤害能力规则强化，原牌区和牌序保留。 |
| 先学会站起来、翱翔在天际、娓娓道来、反复研习 | 原生关键词、攻击命令与牌堆生成命令 | 核对零费与消耗、14／18伤害及加速、2／3回合加速，以及复制的基础／升级版本、每回合次数与 Random 入堆。 |
| 燃烧宝石 | `BurningBlood.AfterCombatVictory` 的 `CreatureCmd.Heal` | 运行时回复值由2改为3，与 MCP 文本一致。继续沿原生回复入口处理单张增减、批量按张结算及生命上限。 |

工作台内部类型修正请求为 `5b3fe6ce-c272-4ddd-821b-b43a2cc8c5c8`；牢笼动态规则和巨像参考记录请求为 `da36103b-67f4-4c32-a8cb-2d694a876d09`。当前导出 r5007，118张启用牌、50组知识关联。
