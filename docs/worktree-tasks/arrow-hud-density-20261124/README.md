## Result and changes

### 后台对局

最新纯那记录于北京时间 2026-11-24 03:11:43 收到，测试版 v0.113.1，Core 2.0.2，进阶 10，第 49 层通关。牌组有「星屑＋」和「倾泻的星光」。星屑结算后续生两支星屑，倾泻的星光按本场飞矢出牌次数生成流星。对局载荷提供牌组、增删牌记录和战斗回合数，缺少飞矢同时在场峰值、帧率和逐次出牌记录。性能复现场景使用同版本隔离战斗。

### 改动

- 飞矢达到 32 支时，按牌种、所有者、目标、升级、基础伤害、剩余回合及重放数共享战斗图标，图标下方标注实际数量。节点、排位和引导线按图标更新。
- 悬停图标或目标可查看实际数量，费用、卡牌数值等个体状态不同的飞矢可分别检查。密集悬停定期更新分组，当前展示的卡牌按战斗全局修正刷新。
- 飞矢结算继续使用原有顺序和动画，收拢在栈内的飞矢从共享图标的位置飞出。画面使用原有资源包。

### 定向验证

同一隔离战斗、完整特效档，每组采集 360 帧。

| 场景 | 原版 HUD 平均耗时 | 优化后 HUD 平均耗时 | 原版 → 优化后场景帧耗时 | 原版 → 优化后图标数 |
| --- | ---: | ---: | ---: | ---: |
| 128 支同状态飞矢 | 4.49 ms | 0.10 ms | 16.67 → 16.67 ms | 128 → 1 |
| 512 支同状态飞矢 | 55.07 ms | 0.27 ms | 61.21 → 16.67 ms | 512 → 1 |

- 512 支悬停时平均 HUD 耗时 0.91 ms，场景帧耗时 16.67 ms，预览计数为 512。混合牌种、改变单个副本费用、改变单个副本倒计时、四支飞矢的逐支悬停和翻页均通过。
- 64 支飞矢在关闭特效时全部正常释放，部署数和箭图标节点均归零。四支飞矢的目标位置、引导线和特效档位切换核对通过。
- 正常打出「星群」将 64 支星屑复制成 128 支，图标显示 ×128，悬停显示两组 ×64。已检查有声录像帧，录像和测试结果归档在 `artifacts/task-deliverables/arrow-hud-density-20261124/`。
