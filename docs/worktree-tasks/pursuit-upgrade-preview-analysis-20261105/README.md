## Result and changes

### 已完成实现

- 追击着色原因：`CatalogCard.OnUpgrade` 对未变化的变量仍调用 `UpgradeValueBy(0)`；原版方法会将 `WasJustUpgraded` 设为 true。追击预览 7、2、1 全绿，原版 TwinStrike 与 CloakAndDagger 只标记发生变化的变量。仅清除预览副本的零增量升级标记后恢复正确着色，定位成立。生产升级逻辑保留本次分析前的行为；最小修正方向是跳过零增量变量。
- `KnowledgeGroupPreview` 的取消、确认在画布中央并列，位于“查看升级”上方，与原版卡牌奖励按钮同行；滚轮输入由预览控件自身处理，适配两版原版界面。
- 工作台知识关键字、游戏中英文提示及定向断言同步；26 张箭矢基础／升级正文移除等待回合前缀，独立徽牌继续显示等待数；生成器同步。
- 两版宝石主体与轮廓等比放大，保留光晕。可见核心高度从画布约 65% 调整到约 91%，接近原版遗物约 93% 的占比。
- `ArrowHud`、其特效、悬浮预览和强化标记使用战斗场景的绘制顺序；第二行遗物参照位置采用原版默认位置，避开暂停页隐藏遗物栏的动画偏移。
- Steam 能量故障由 RitsuLib 命中补丁冲突导致：纯那提前替换原版伤害调用，RitsuLib 再应用时找不到目标并中断补丁安装。将纯那批次补丁排在最后，保留 RitsuLib 包装调用，恢复后续能量钩子；嵌套不同来源的伤害保留独立批次。
- `loader/`、`src/Compatibility/`、项目与构建脚本增加共同入口、Stable／Beta 实现；发布包包含 `lib/`，开发启动脚本递归复制。最低游戏版本同步为 0.107.1。
- 余星基础／升级使用 `{N1:diff()}` 加一个能量图标；工作台牌面约定已通过 MCP 更新（r2595）。
- 双星使用 `ModifyCardPlayCount`／`AfterModifyingCardPlayCount`：下一张非能力牌本次临时增加一次重放，仅正常付费一次，计入次数后消耗效果。工作台当前 r2597，游戏牌面与元数据同步。移除旧 JH19 再付费分支。
