# 卡牌伤害实现约定

## 飞矢预计伤害

- 每次刷新都按当下的战斗状态计算。读取已布置飞矢的伤害、目前确定的目标、命中段数、重放次数，以及当前已生效的伤害修正。剩余回合用于分组展示，各组都读取同一个时点的状态。
- 格挡不计入预计伤害，当前已有的格挡也不扣除。未来的出牌、伤害触发和能力效果不进入计算。飞矢命中时走本体实际结算。
- 回归检查覆盖同一飞矢当前状态变化后数值刷新、敌人当前格挡变化时数值不变，以及前一支飞矢可能触发蜷缩时，后续飞矢仍按刷新时的状态估算。

## 通用伤害强化退役

移除附加在卡牌实例上的通用伤害加成和额外命中机制。清理该机制的伤害及段数补丁、专属状态与复制、角标、提示、本地化和测试。卡牌自身的多段攻击和按条件决定的命中次数继续按牌效处理，例如「耀眼的身姿」按已耗尽的「渴望」计数，「猛烈」按当前手牌类别计数。

旧版研究牌已有的牌内条件命中通过各自的研究进度保留。通用强化的旧字段不参与战斗结算。 [九张牌迁移](../worktree-tasks/native-style-review/README.md#九张事件知识牌清理计划)
