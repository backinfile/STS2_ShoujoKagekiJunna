## 结果

基线为 `main` 的 `387a38e`。工作树为 `../worktrees/STS2_ShoujoKagekiJunna/arrow-live-damage-preview`。

- 飞矢悬停卡面使用本体卡牌预览。本体按实际牌堆决定是否执行战斗修正，飞矢堆原先被排除。悬停缓存也不会因能力变化失效。血条旁的飞矢伤害预估已有独立的本体伤害修正入口。
- 让飞矢堆中的牌调用原生动态变量计算时启用战斗修正。战斗状态变化时使悬停显示缓存失效，下一帧重新计算当前目标的数值。
- 用 `junna_hover_density live-damage` 实机核对保持悬停时的卡面。旧版在五种条件下都显示 25。修复后，在基础伤害、加 5 力量、再加虚弱、目标易伤、移除力量的情况下，依次显示 25、30、22、33、28。Beta、Stable 和测试模组编译均无警告或错误。
- 正常打出「强劲的箭」和「两人的心跳」后，8 点力量使已布置飞矢的悬停卡面和敌人血条旁的预估同时从 25 更新到 33。按约定删除了实机录像和截图。

## 其他重构发现

- `4ad21b1` 新增了飞矢完成时对本体「撕裂」的手动出牌回调。实机复现「连珠箭」完成后重打自身时，本体再次登记同一卡实例并抛出重复键异常。
- 同一重构为转换成飞矢的本体攻击增加了血条伤害预估。该入口只检查固定的 `RepeatVar`，本体 `Flechettes` 和 `Barrage` 使用 `CalculatedHitCountVar`，会被按一次命中估算。这项结论来自源码对照。
