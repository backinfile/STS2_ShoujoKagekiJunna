# 卡池效果实现

基准为工作台 MCP 导出 r2550：115 张有效牌面，含 106 个新增模型、原有 9 张牌和 19 组知识关系。交付前对照 r2561，效果、数值、费用、类型与知识组范围保持一致。游戏内展示文案单独维护，见下文。

`card-pool.json` 保存逐牌基础版、升级版、内部类型、奖励入口和关联数量。生成脚本只读取 MCP 导出副本；`CardEffects.cs` 显式实现具体指令，运行时不解析牌面文字。

## 本次确认的规则

- 学无止境保持 0 费，基础获得 2 点能量，每次升级使获得量增加 1。
- 换位选到 X 费牌时，X 按执行交换时的当前能量折算为数字。两张牌交换数字费用，持续本场战斗。原 X 牌的 X 载荷使用之后实际支付的能量。
- JT02 的选择范围按工作台结算备注为手牌；其他布置保持原样。
- 普通常规牌池有 88 个入口；3 张基础牌、关联牌、生成牌及远古版满弦射击按各自来源处理。

## 逐牌核对修正

- 连射、横扫、箭雨和即兴生成的飞矢继承来源牌升级状态，再写入记录伤害；升级飞矢等待 1 回合。
- 挺身反抗／默然忍受切换时保留实际卡牌身份，完整执行当前形态的重放，再更新名称、牌面、目标类型和印刷费用。
- 再上弦只接管默认弃置去向；飞矢等消耗牌仍正常消耗。
- 星海与晨星按固定数值费用统计，筹备排除 X 费和不可打出的牌。
- 即兴按本体的攻击伤害事件统计本回合次数，安装能力沿用已有记录；其他模组技能产生的攻击伤害也能触发。
- 本体重放仅重复牌效；付费再次打出另计一次实际出牌。追击在出牌开始时记录等待期间的攻击／箭矢次数。
- 星芒响应实际获得、支付与失去能量；直接设定能量沿用设定操作。
- 缓步起行先尝试抽取攀登险丘，再独立降低各牌堆中所有攀登险丘的费用；抽牌堆没有目标或受到不可抽牌限制时，减费仍然生效。

## 游戏内文案

参考本体全息影像、万物一心、无尽刀刃、回响形态和肾上腺素等牌，统一效果分行、触发句式、关键词与关联牌名高亮，以及能量图标。正文采用本体 24×24 的蓝色能量图，避免大图把正文压小；箭矢等待回合继续显示在独立标牌上。

`tools/assets/card-text-zhs.json` 保存展示措辞，动态数值沿用工作台数据。`python tools/assets/generate-card-catalog.py .tools/card-coverage/completion-workbench.json --text-only` 只更新本地化；不会重写运行数值、模型、配图或工作台。

本次必要验证：115 张牌的基础、升级预览和升级描述均成功格式化；缓步起行基础／升级版在无抽取目标、不可抽牌两种情况下的 20 项费用断言通过。以本体全息影像作参照，实机抽查缓步起行、观摩的字号、换行和图标。结果与截图保存在 `artifacts/card-text/`。

- Release 编译通过，无警告或错误。
- 115 张牌的基础／升级描述和关联悬浮提示构造通过，所有新增模型都有明确效果分支。
- 48 项基础断言与 23 项事件断言通过：真实支付、X 费、箭矢完成与重新部署、知识获取与复制、无限升级、回合限次、持续伤害、生成飞矢等。
