## 计划

读取工作台的飞矢契合与本体药水设计约定。以 JP02 当前的手牌转飞矢效果确定有明确用途的液体，将准备、等待与结果做成可见的过程。生成工作台图标，经本地清理与缩图检查后，同步更新药水条目和命名约定。将工作台的名称、成品图标和药效同步到 Mod，保留旧档所用的药水 ID，并在 AGENTS.md 中记录本地清理要求。

## 结果

- 纯那罕见药水 JP02 定名为「显影液」，效果为「选择任意手牌作为3回合的飞矢打出。」。显影液让已曝光相纸的潜影逐渐显现。放入相纸对应选定手牌，显影过程对应飞矢倒计时，舞台画面出现对应手牌打出。参考本体「流动铜液」的液体命名和「瓶中船」以内装物直观表达主题的做法。[本体药水记录](../junna-potions-workbench-20261111/native-potions.json)、[ILFORD 相纸显影资料](https://www.ilfordphoto.com/amfile/file/download/file/1826/product/728/)。
- [成品](v5/icons/photo_developer.png)为暗房试剂方瓶，红色液面将相纸分成浅色与已显影两部分。聚光灯下是原创舞台少女的背影，以短发和简洁舞台裙形成剪影，姿态面向舞台深处。用内置 ImageGen 生成正立方瓶，再局部重绘演员。按 1254×1254 原尺寸用 GPT Image 2 Artifact Cleaner 清理，strength 和 interior blend 均为 0.25，透明通道和深色轮廓保留。成品整体逆时针旋转 12 度，导出 256×256 RGBA PNG。
- 核对原尺寸的背向站姿、短发、裙摆、液面和透明轮廓。药水栏尺度核对瓶形、红色液面与相纸的大色块。[32、64、128 像素对照](v5/small-size-review.png)、[角色重绘提示词](v5/prompt.txt)、[生成原图](v5/originals/photo_developer_upright.png)、[清理记录](v5/cleanup.json)、[旋转记录](v5/rotation.json)。
- 「本体药水命名与图标特点」已更新。先读当前效果，从药液材料、制剂类型或具体用途确定名称。对于等待后才起效的设计，优先取能表现准备、等待与结果的具体过程。示例使用显影液与瓶内原创舞台少女的背影。
- 工作台 r5950 更新背影成品与工作台配图示例。MCP 与公开快照回读到正确名称、效果、配图和新约定，公开 PNG SHA-256 与本地成品一致。

- 保留可载入旧存档的药水 ID `JUNNA_SPORTS_DRINK`。罕见药水在游戏中显示「显影液」及飞矢提示，使用原生手牌多选。选中的实际卡牌沿现有转换流程作为 3 回合飞矢布置。未选牌保持原位。
- Mod 图案与工作台最终 PNG 的 SHA-256 一致，配套白色轮廓由 256×256 成品的透明通道扩张 2 像素生成，保留原资源路径和导入 UID。根目录 AGENTS.md 已加入用户指定的本地去摩尔纹说明。
- 正式版 v0.111.1 与 Beta 使用同一代原生选牌栈。构建时修正既有正式版条件，以便按各自游戏引用生成 Stable 0.107.1、Main 0.111.1、Beta 0.113.1 实现。三个实现和加载器均为 0 警告、0 错误，Godot 导入及 PCK 打包通过，使用 Core SDK 1.9.7。
