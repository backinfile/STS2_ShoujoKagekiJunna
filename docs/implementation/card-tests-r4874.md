# r4874 逐牌测试条目

本次包含 104 张牌。每张基础与升级均执行显示、正常、空资源和配合场景。

每个测试结果保存实际值、预期值与通过状态。视频在准备完成后开始录制，通过游戏的悬停、出牌、选牌和回合结束操作展示结算。

## JG03 练习

- 显示。核对卡名、基础与升级费用、类型、稀有度、牌效数值、卡图、关键词、提示和升级预览。
- 基础结算。选择一张手牌，使其额外造成1次伤害。  消耗。
- 升级结算。选择一张手牌，使其额外造成1次伤害。
- 费用边界。能量恰好足够与不足1点。禁止打出时保持牌堆、能量、目标生命和布置状态。
- 资源边界。清空抽牌堆与可选对象后结算，核对无效目标、空集合、手牌上限、消耗或弃牌去向。
- 改编配合。将该牌作为零费、5回合箭矢打出，核对等待期间的伤害和格挡，以及完成后的牌效、能力安装和闪耀扣减。
- 录像。悬停展示牌面，合法打出并完成本牌效果，保留结算前后状态与对应MP4。
