## 原始请求

## 方案

把提示贴在飞矢图标的外沿，保留原倒计时和导线。普通的箭列、密集箭组、群体飞矢用同一套视觉语言。

| 预览状态 | 表现 |
| --- | --- |
| 确定加速，仍需等待 | 淡蓝细描边，亮起时沿边缘扫光一次，随后维持细边。 |
| 确定加速到 0 | 保留同一套描边和扫光，叠加较宽的蓝色光晕、箭尖星芒和一次扩散闪光。 |
| 尚未指向目标或选项、取决于随机结果、等待后续触发 | 无悬停特效。 |

悬停切换时及时更新，移开时收起。保留原倒计时数字，真实出箭继续使用现有动画。大批飞矢同时完成时，以静态星芒承担区分；简化特效时可只画静态形状。

## 覆盖范围

基线为 `main` 的 `319be75`，当前卡池版本为 r6148。

| 卡牌 | 预览范围 |
| --- | --- |
| 列阵（JA43） | 自己已部署的所有适用飞矢减 1。 |
| 开幕（JA71） | 自己已部署的所有适用飞矢到 0。 |
| 尽情大闹（JK84B） | 所有面向敌方的飞矢减 1。出牌瞄准哪名敌人不改变这个范围。 |
| 轮到你了（U_CARD_063） | 只推进明确以自己为目标的飞矢，减 1。 |
| 开辟前路（U_CARD_079） | 随瞄准更新，只推进目标集合包含所选敌人的飞矢，减 1。 |
| 更近一步（JA119） | 手牌悬停和选项界面的空白区域无特效。指向「自己」或「敌人」时只预览对应范围，减 1。 |
| 应援（JA177） | 应援完成时所有适用飞矢减 1。只有打出时即可完成应援才显示提示。 |
| 加速（JA105） | 安装后作用于之后打出的飞矢。能力牌本身悬停时，当前部署没有加速对象。 |
| 遥远星辰（JK37C） | 安装后由实际耗能为 0 的后续出牌触发。随机推进无悬停特效。 |

兼容仍可进入战斗的旧实例时，沿用「从容应对」「措辞」「乐谱」的实际范围。旧能力「娓娓道来」「刺痛」分别在回合开始、受到未格挡的攻击伤害时触发。

## 实现与验证计划

- 让战斗和预览共用只读的目标筛选及加速回合数，读取牌实例的实际 `Turns` 和飞矢的 `Remaining`。满足完成条件时显示第二档。只预览本次可以确定的直接推进，避免尝试执行牌效或采样战斗随机数。[战斗筛选和结算](../../../src/Combat/Arrows/ArrowCombat.cs) · [分支选项](../../../src/Combat/Cards/CardChoices.cs)
- 用实际手牌焦点、当前瞄准对象和选项焦点驱动箭标的独立表现。复用现有箭标位置、层级和简化特效设置。悬停状态不抢占箭标或卡牌的输入。[飞矢 HUD](../../../src/UI/Arrows/ArrowHud.cs) · [实际倒计时和出箭动画](../../../src/UI/Arrows/ArrowHud.Feedback.cs)
- 实现后定向看一组混合倒计时的飞矢，以及选敌切换、选项切换和移开后复位。用同一战况对照显示范围和实际牌效，再以密集箭列检查可读性。

## 结果

- 手牌焦点、选敌和「更近一步」的选项焦点驱动箭标外沿。确定受加速的飞矢显示蓝边，即将完成的在蓝边上叠加光晕和星芒。完整特效下播放一次扫光和完成闪光，简化特效下保留静态提示。
- 加速牌与预览共用目标筛选和推进量。悬停只读取战斗状态。随机和未确定目标的预览保持熄灭。
- 旧正式版、当前正式版、Beta 和加载器构建均为 0 错误、0 警告。MegaDot 资源导入和 PCK 打包通过。
- Beta 隔离实机使用满解锁、最小化及静默设置。用 5 支剩余 1／2 回合的飞矢核对了 8 组悬停状态。列阵同时显示两档光效，开幕给所有飞矢加上完成光效。开辟前路随目标更新，未指向敌人时保持熄灭。应援尚需等待和移开卡牌时也保持熄灭。打出列阵后，2 支完成，其余 3 支各剩 1 回合。
- 更近一步的两个原生选项分别点亮 1 支自用飞矢和 2 支敌方飞矢。打开选项和移到空白处时均无提示，实际选择自己后只完成自用飞矢。安装遥远星辰后悬停零费牌，随机加速未显示提示，现有飞矢倒计时保持原值。
- 实现已基于同步后的 `main` 提交 `26e506a` 整理。最终实机录像为 26 秒，已验证视频及音频轨道。按照最新要求，录像与其他临时验证产物随任务工作树清理。
