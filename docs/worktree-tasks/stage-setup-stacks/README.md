## 简要计划

- 从 `main` 的 `d94950c` 创建独立工作树 `../worktrees/STS2_ShoujoKagekiJunna/stage-setup-stacks`。
- 核对布置舞台与同类 Power 的层数、选择及触发，复用原生选择和现有飞矢流程。
- 定向验证，提交后等待合并和清理确认。

## 结果

- 布置舞台将可选牌数加到原生 Power 层数。回合结束、手牌清理前，按当前层数开启一次可跳过的手牌多选。所选原牌批量布置为 3 回合飞矢，状态栏与提示使用同一层数。
- 布置舞台的选牌界面显示“选择 X 张牌作为 3 回合飞矢打出。”。张数取当前层数，回合数取牌效。状态栏沿用原文，通过原生提示读取当前层数。两套本地化及生成器同步。
- 舞台少女心得将同一轮换类别的份数合并为一次多选，选择数受候选数和剩余手牌容量限制。错开打出的份数各自推进轮换，每个当前类别仍有自己的选择。
- 对照原生 `ToolsOfTheTradePower` 按 `Amount` 一次发起手牌选择。另核对了铭刻的战后奖励。逐份领取允许先复制一张知识牌，再从更新后的牌组领取下一份奖励，保留现有领取方式。
- `src/Models/` 修改叠层、触发与提示渲染，`data/card-rules.json` 及生成代码记录布置舞台的层数来源。两套选牌文案及生成器同步数量占位符，`tests/Integration/FullCardAuditProbe.cs` 增加多选及容量断言。

## 验证

- Stable、Main、Beta、加载器和定向测试模组均以零警告、零错误编译，MegaDot 打包通过。卡牌规则生成检查通过。
- Beta v0.113.1 满解锁、最小化、静默隔离实例中，仅对两张牌运行 16 组定向用例，420 项断言通过。覆盖基础和升级混合叠加、零张确认、空手牌、批量部署、同类别与错开轮换、手牌容量和禁止抽牌时直接移牌。
- 用原生出牌、结束回合与选牌复验两张牌。布置舞台以一轮选择部署打击和防御，下个玩家回合两张都显示剩余 2 回合。舞台少女心得显示“选择2张知识牌放入手牌。”并在一轮选择中将两张牌移入手牌。
- 最终包中正常打出布置舞台和布置舞台+，在状态栏首次报告 1 层及 2 层时读取实际提示，两个数字即时更新。
- 调整选牌文案后，实机在 2 层时显示“选择2张牌作为3回合飞矢打出。”，两张原牌均成功部署。重跑布置舞台的 8 组用例，186 项断言通过。
- 实机演示保存在 `out/deliverables/stage-setup-stacks/stage-power-stacks.mp4`，含游戏音轨。
