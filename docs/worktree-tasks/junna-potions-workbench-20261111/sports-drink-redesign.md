# 运动饮料从零重做

本轮重新逐张观察本体提取素材中的全部63张药水图标，涵盖普通20、罕见20、稀有20、事件2、衍生1。图像按256×256原尺寸检查，全部源文件与现有清单同SHA-256。完整63项形状、颜色、装饰记录见[native-potion-icon-design.md](native-potion-icon-design.md)。这里的设计思路由成图反推。

## 设计归纳

| 维度 | 本体观察 | 对新运动饮料的应用 |
| --- | --- | --- |
| 形状 | 肌肉、闪电、星星、四叶草进入整体轮廓；锅、瓮、纸盒通过具体容器本身说明用途。攻击、技能、能力同族可共用瓶形。 | 运动瓶采用上下饱满、中腰收窄的握持结构；以运动壶嘴说明饮用用途，使容器本身表达训练补给。 |
| 颜色 | 一种液体主色配深浅色块；玻璃边线随配色变化；木塞、金属盖和布采用材质色。等级不规定液体颜色。 | 橙金饮料、深橙阴影和浅色玻璃边，蓝绿色瓶盖构成局部对比。与知识药水的蓝色、箭雨药水的紫色区分。 |
| 装饰 | 骨塞、链条、符纸、骰点或船形成一个主要识别点，气泡和反光补充材质；简单和复杂均不绑定稀有度。 | 收腰与推拉壶嘴承担识别；少量气泡和宽反光，不添加文字标签或额外训练器械。 |
| 实体结构 | 狡诈药水、瓶装潜能、格挡药水都用分段、侧面、瓶沿、内外边和液面形成可盛装的物件。 | 同轴瓶口和壶嘴、厚底、内腔与药液液面必须清楚；不画成平面的健身符号。 |
| 制作与小尺寸 | 本体轮廓、液体主色和主要物件在药水栏尺寸下仍成立。 | 从零生成正立稿，检查壶嘴与瓶颈轴线，清理后整体倾斜18度；检查32、64像素和本体并排效果。 |

## 当前设计

名称沿用“运动饮料”，牌效保持“所有手牌获得9点伤害加成。”。伤害加成按工作台规则对应纯那的日常锻炼，收腰运动瓶与饮用壶嘴承接训练补给主题。新图从空白画布生成，不使用旧运动饮料图作为输入。

本轮63图复核记录与生成成品位于docs/design/assets/potions/2026-11-11/v10/。
