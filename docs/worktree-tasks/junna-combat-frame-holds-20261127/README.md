## 计划

以传统动画的延长曝光为参考，按姿势取帧，验证原有动作时长、放箭时点和待机衔接。[Sony Pictures Imageworks 动画制作说明](https://www.imageworks.com/our-craft/feature-animation/movies/spider-man-spider-verse) · [Godot 离散轨道说明](https://docs.godotengine.org/en/4.5/engine_details/file_formats/tscn.html#animation)

## 结果

正式场景采用最后一次试玩的 480×832 姿势。普通待机循环为 3.8 秒，持弓手和弓一起运动。可操作回合持续待机两个循环后，纯那撩一次头发；出牌或使用药水会重新计时。场景复用原有角色缩放与脚底位置。[战斗场景](../../../ShoujoKagekiJunna/scenes/junna_combat.tscn) · [待机触发逻辑](../../../src/UI/JunnaIdleGesture.cs)

待机与撩发均以完整弓图的两个弦扣确定弦向。弦在前臂和红色袖口前方经过，下段由裙身遮挡。普攻、取箭、射箭、受击、胜利和战败共调整 41 个姿势中的空手位置。普通攻击收势时，手掌从裙边顺势落下；其他动作按各自的动作轨迹过渡。图集沿用经本地 GPT Image 2 Artifact Cleaner 处理的 WanGP 原画，清理强度与内部混合均为 0.25。

最终预览在 Beta 实机录制了 32.9 秒连续战斗和单独的 5.9 秒死亡片段，覆盖出牌、取箭、放箭、受击、撩发和结束动作。正式场景沿用原有的待机资源路径与 UID，新增动作衔接和空手收势图集。

合入前按仓库配置构建 Stable、Main、Beta 及加载器，并通过 MegaDot 打包。从试玩包与正式包分别加载战斗场景，逐一播放 8 段动画，137 个关键帧的纹理内容、图集区域、时点、缩放和位置均一致，默认姿势与后续动画设置一致。同步出牌回调时保留主分支的费用记录、零费飞矢响应及飞矢计数。
