## 已确认原因

- 脑蛭「分享知识」和海玻璃使用 `NSimpleCardSelectScreen`。该界面遗漏在知识堆叠支持列表之外，未创建关联牌节点；对应悬停和右键入口也未统一适配。
- 通用网格候选保留原生物理卡牌及选择结果；已有牌堆中的卡牌继续按实际对象显示。
- 箭阵的能力触发调用共用 `Block` 方法，原来使用 `ValueProp.Move` 并传入安装能力时的卡牌播放记录，导致脆弱和敏捷按卡牌格挡修正。对照原生 `AfterimagePower` 改为 `ValueProp.Unpowered`，并移除卡牌播放来源。
- 共用能力格挡入口统一采用能力结算；卡牌打出时的即时格挡继续经过原有卡牌路径。
