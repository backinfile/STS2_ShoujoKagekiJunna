- 坚毅最适合对照张弓：同为1费防御加手牌处理；坚毅升级才获得选择权。张弓基础8格挡、可选择，后续还保留原牌效。
- 主动消耗通常换取即时收益并精简本场战斗循环；五回合箭矢保留原牌效、免去所选牌本次原费用，并增加布置、加速、额外触发等配合。选低价值牌时以调度为主，选高费牌时延迟代付的价值更突出。
- 痛殴读取材料牌的伤害并转成未来收益，适合对照材料质量；五回合箭矢承接整段原牌效，覆盖类型更多。批量玩法可参考重振精神、恶魔之焰和添柴，但还需计算一次性布置多枚箭矢的数量收益。
- 补充参照破灭 Havoc：1→0费，自动打出抽牌堆顶并强制消耗，属于抽牌堆效果；可用来评估代付费用的价值，与确定的手牌选择及5回合延迟分别对照。
