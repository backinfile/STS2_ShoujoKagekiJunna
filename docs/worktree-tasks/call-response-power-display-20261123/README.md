## 结果

- 批注中的白色笔画来自原生手牌序号与回声弧重叠。`src/UI/Cards/CategoryResponseVisuals.cs` 在显示序号时将回声弧放在序号右侧，关闭序号时居中。战斗中调用原生序号刷新时同步调整已有标记。
- `src/Models/CategoryResponsePower.cs` 在匹配出牌换档后发出原生能力闪动事件。角色身上的闪效和状态栏都取换档后的图标。大图标按当前轮换取路径，避免使用原生缓存中的首档书页。
- Beta v0.113.1 隔离实机在满解锁、最小化和静默状态下对照修复前后。开启手牌序号后检查八张手牌的常态与悬停。打出防御时保持知识档，依次打出默然忍受、引弦和星坠时，状态切换至飞矢、闪耀、知识，各次角色闪效显示相应图形并正常抽牌。
- 实机从关闭序号启动，对默然忍受和星坠测得标记横向偏移为 0。在同一场战斗开启再关闭序号，经原生手牌刷新后，偏移依次为 36 和 0。关闭序号后用正常出牌复查三档轮换。
