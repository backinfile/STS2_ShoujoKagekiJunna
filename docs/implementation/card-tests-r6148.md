# r6148 逐牌效果测试

覆盖 98 张已启用牌，包含初始牌、衍生牌和关联牌。基础版与升级版分别验证。

自动场景分别使用常规资源、空资源、机制组合及满手牌。触发专项用卡牌的实际对象、目标、牌堆、费用与前后状态作为依据。

每段主要效果录像展示一次可观察的真实流程。录像涉及自然回合或胜利时，按游戏操作推进；其余分支的执行结果见逐牌断言与专项记录。

## JA15 闪耀的梦

- **准备状态**　抽牌堆至少4张，手牌有4个空位。
- **操作**　打出闪耀的梦，先观察布置，再结束回合或打出开幕。
- **预期**　结算前抽牌堆无变化。完成时，基础抽3张，升级抽4张。空堆时0张，满手按正常抽牌规则处理。
- **基础牌面**　抽3张牌。
- **升级牌面**　抽4张牌。
