## 复现与证据

观察模组：`tests/DesireArrowVideos/NativeDesireProbe.cs`。脚本：`tests/DesireArrowVideos/record-cases.py`。在已有的隔离单人战斗中加载测试DLL和JSON清单，启动前将 `JUNNA_DESIRE_OUTPUT` 指向观察输出目录。

```powershell
dotnet build tests/DesireArrowVideos/DesireArrowVideos.csproj -c Release -p:CoreApiPath=<Core API DLL> -p:JunnaAssemblyPath=<Junna Beta DLL>
python tests/DesireArrowVideos/record-cases.py --port <随机隔离端口> --output-dir <观察输出目录>
```

证据目录：`artifacts/task-deliverables/desire-arrow-videos-20261111/`，包括七段原片、带场景标题合辑、各步前后状态、118项结果、录制回执、运行程序集哈希及分场景索引。

本轮展示上述七组场景；X费、自动打出与多玩家的其他分支仍需独立场景验证。

## 绝美的凋零问题的源码核对

用户同时询问“绝美的凋零现在战斗开始会打出吗？”。当前 `BeforeHandDraw` 调用 `OpenCombat`，首回合且尚未处理开局时，遍历战斗实际牌中的JK37，找到首个存活合法敌人后走 `CardCmd.AutoPlay`。作为9回合箭矢布置，完成后造成50/60伤害。main与本任务分支在此逻辑一致；该牌的真实开局流程未纳入本轮七段录像。
