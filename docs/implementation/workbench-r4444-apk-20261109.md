# 工作台 r4444 与 Android 合包

## 内容

- 将工作台 r4444 的 107 张启用牌、20 个知识组、基础与升级牌效、卡图及本地化同步到 Mod。
- 新增娓娓道来、星群、应援、群星闪耀、融会贯通、知识的力量、星屑、失势、一无所有。娓娓道来沿用已有模型。
- 同步多重射击与檄文的连击、舞台研究与观摩的数值、更近一步的分组选项、戏中戏／捕鼠机的卡名和配图，以及瞄准射击的稀有度。
- 按用户确认将星屑设为攻击箭矢、单个敌人目标，并将目标与子类型通过 MCP 同步回工作台。
- 星群复制执行开始时的有效箭矢，保留当前等待、目标、伤害修正及重放，不产生额外出牌事件。
- 群星闪耀将单体敌人箭矢的攻击扩展到所有敌人；融会贯通打出手牌内实际关联牌；知识的力量按回合限制触发。
- Karen Android 的选角、开局及续档策略允许华恋与纯那；对应提示同步维护中、英、日文。
