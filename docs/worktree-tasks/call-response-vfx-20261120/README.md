# 呼喊与回应常驻特效

## 用户原始输入

> worktreetask 你来设计下呼喊与回应这张牌的常驻特效。要求能明确提示玩家下一张触发的牌是什么。你先分析分析特效要求，然后用imagegen设计几种我来选择

## 计划

核对工作台规则、运行时实现和战斗布局。以同一触发状态比较角色旁提示、舞台灯位和手牌提示。用内置 ImageGen 制作概念图，保留原图并用本地 Artifact Cleaner 清理后交付选型。

## 特效要求

- 打出能力后显示「下次触发」及「知识牌」「飞矢牌」「闪耀牌」之一。对应图形使用书页、箭、四角星。保留文字和形状区分，颜色只用于辅助辨认。
- 手中每张符合当前条件且可打出的牌显示同一角标。当前无可打出的匹配牌时，类别提示持续可见。费用变化、抽牌和手牌重排时，角标跟随实际卡牌。
- 每次符合条件的出牌使该份能力按「知识 → 飞矢 → 闪耀 → 知识」推进一档。实现从能力状态读取类别，触发后和手牌角标一起更新。满手或抽牌被阻止时照常推进。不匹配的牌和飞矢完成保留当前类别，跨回合延续。
- 多份能力独立轮换。显示当前生效的各类别，同类合并并标记份数。同一张多标签卡可满足不同份能力，每份只触发一次。卡牌角标最多按命中的当前类别组合显示，避免重复堆叠角标。
- 常态保持文字和图标稳定，换档时用一次短亮或淡入体现回应。装饰动画可以跟随特效设置关闭，文字和角标继续显示。角标避开费用、卡名、升级与已有标记，场内提示避开血条、状态图标、飞矢 HUD 与目标线。

规则依据为工作台 junna 的 U_CARD_016（revision 5707）、[能力结算](../../../src/Models/CategoryResponsePower.cs)、[分类判定](../../../src/Combat/Cards/CardTutors.cs)、[能力说明](../../../src/Models/CatalogPower.Description.cs)和[现有回归用例](../../../tests/Integration/LatestCardEffectsProbe.cs)。

## 第二轮设计

**Power 换图标，手牌贴同款角标。** 动态提示放在纯那血条下面的原生 Power 区。底框和两道短回声纹维持同一款式，中心图形和色彩跟随当前需求变化。知识用暖金书页，飞矢用冰蓝羽箭，闪耀用浅紫四角星。三种形状在灰度下也应可辨。悬停复用现有 Power 说明「打出〔类别〕牌后，抽〔数量〕张牌」。

手牌只在可打出且符合条件时显示角标。角标贴在牌顶、牌名右侧，跟着卡牌位置、扇形旋转和抬起走，给左侧费用和画像下缘的伤害／命中标记让位。如果同一位置无法避开牌名，角标上移到卡框外缘。用深底浅色图形保持静态读数，类别推进时新 Power 图标和新匹配角标同步短亮约 160 毫秒。原生可打出描边继续承担原有反馈。

打出符合条件的牌后，Power 按「知识 → 飞矢 → 闪耀」切换，角标按更新后的状态重新匹配。手中没有可触发候选时，Power 继续显示当前类别。满手、阻止抽牌和跨回合按原结算同步。多份能力同时等待不同类别时，在同一个 Power 控件里横排当前类别符号，每个符号保留正常图标尺寸；同类合并显示，具体抽牌数量在悬停说明中按类别汇总。多标签手牌用一个角标容纳实际命中的类别符号。

首轮的独立文字条、角色旁提示牌和舞台灯由这一版的原生 Power 与手牌角标取代。图片用于选型。

## 公共图形与叠加规则

三态图标共用左上角同一组金色回声弧，大小、颜色和位置一致，用来识别「呼喊与回应」。右侧的绿封面书页、蓝羽箭、紫红四角星分别表示当前所需类别。右下给原生 Power 数字角标留位，数字表示每次触发的抽牌张数。手牌仍用同款小图形标记当前类别的可打出候选，抽牌数字显示在 Power 上。

首次打出能力时从知识开始，抽牌量为 1。再打出一张能力时，沿用同一套轮换进度及当前类别，抽牌量加 1。每次打出匹配牌时按数字抽牌，然后推进一档。比如等待飞矢时叠加第二张能力，图标仍是飞矢，右下数字改为 2。下一张飞矢触发后抽 2 张，然后切至闪耀，数字保留 2。这条设计取代前几轮的多份独立轮换方案。

[新版战斗预览](power-icons-v4/battle-preview.png)在原截图上示意「等飞矢、抽 2 张」的界面，附 24 像素三态显示。三枚成品图标为[知识](power-icons-v4/knowledge.png)、[飞矢](power-icons-v4/arrow.png)和[闪耀](power-icons-v4/shine.png)，数字由界面叠加。保留内置 ImageGen [回声原图](power-icons-v4/echo-original.png)，用本地 Artifact Cleaner 按原尺寸清理（strength 0.25、interior blend 0.25），再叠放到第三轮图标上。核对了透明轮廓、三枚图标的回声弧像素一致性及小尺寸辨识。[清理记录](power-icons-v4/cleanup.json)、[提示词](power-icons-v4/prompt.md)。

### 实现结果

「呼喊与回应」使用一个 Power 和一条知识 → 飞矢 → 闪耀轮换进度。第二张及后续能力只累加每次触发的抽牌量。原生 Power 数字使用总抽牌量，说明显示当前类别。三态共用金色回声弧，符合当前条件且可打出的手牌显示同款图案。手牌标记放在牌顶靠中间，避开相邻牌的费用与卡名。

已通过 Beta、Stable 发行编译、定向测试模块编译、卡牌元数据校验和 MegaDot 资源导入及打包。用隔离 v0.113.1 游戏在满解锁、最小化和静音状态做了 13 项正常出牌检查，核对首次安装、不匹配牌、共享进度、叠加后抽 2 张、多标签触发一次、跨回合及三态画面。未运行全量回归。录像保存于 `out/deliverables/call-response-vfx-20261120/call-response.mp4`，含引擎内部音轨。
