# 逐牌结算清单

范围：115张当前有效牌与2张专项加练选项牌。基础版与升级版分别执行正常结算、共同边界及下表适用条件。

- 正常结算核对实际支付、伤害、格挡、抽牌、生成、选择、延迟完成、关键词和最终牌区。
- 每张牌检查不可打出；有固定费用的牌另检查能量不足。伤害牌检查加成、额外次数、格挡和多目标隔离。
- 箭矢分别检查布置当回合不减计数、次回合减1、同回合去重及目标死亡后的处理。
- 选择牌检查空候选、资格、实际实例与牌区；专项加练第一步选择牌堆，第二步可确认0～3张。
- 持续效果另以事件探针核对触发、限次、回合重置、到期、施加快照与叠加。形态变化、知识组获取、复制、无限升级及能量设置使用组合场景。
